# Artronic · site

Le site public d'Artronic, servi par GitHub Pages : https://nazimdebieb.github.io/artronic-site/

- `index.html` : la page du studio, avec la liste des jeux ;
- `pop-archer/` : la page de Pop Archer et sa politique de confidentialité (`pop-archer/privacy.html`, le lien à donner au Play Store).

Aucune ressource externe : polices et images sont dans le dépôt. Le code des jeux est dans le dépôt privé `artronic-games`.

Mise en ligne : **Settings → Pages**, Source **Deploy from a branch**, branche **main**, dossier **/ (root)**.
