# Artronic · site

Le site public d'Artronic, servi par GitHub Pages : https://nazimdebieb.github.io/artronic-site/

- `index.html` : la page du studio, avec la liste des jeux ;
- `firefly-trail/` : la page de Firefly Trail et sa politique de confidentialité (`firefly-trail/privacy.html`, le lien à donner au Play Store) ;
- `pop-archer/` : la page de Pop Archer et sa politique de confidentialité (`pop-archer/privacy.html`, le lien à donner au Play Store) ;
- `play/` : la page « lien en bio » de TikTok (@artronic.game), qui réunit tous les jeux avec leurs liens Google Play : https://nazimdebieb.github.io/artronic-site/play/ (le lien Pop Archer porte `referrer=utm_source=tiktok…` pour voir les installations venues de TikTok dans la Play Console). `img/` contient le logo Artronic, les favicons et l'image d'aperçu `og-play.jpg` (1200×630) affichée quand le lien est partagé.

Aucune ressource externe : polices et images sont dans le dépôt. Le code des jeux est dans le dépôt privé `artronic-games`.

Mise en ligne : **Settings → Pages**, Source **Deploy from a branch**, branche **main**, dossier **/ (root)**.
